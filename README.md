# MapEditor

### ハイキングマップデータの編集

- 複数の GeoJSON ファイル（GeoReferencer 等で生成した地域別ファイル）と、Excel(.xlsx) の GPS ポイントデータを読み込み、
  国土地理院地図の上で**ポイント／ルート／スポット／エリア**を編集して、1 つの統合 GeoJSON として出力する。
- あわせて、登山道の**通行止め・通行困難地点**を登録し、**専用の GeoJSON ファイル**として入出力する。
  このデータは統合 GeoJSON とは完全に分離しており、統合 GeoJSON の読み込み・出力には含めない。

**本アプリは公開を行わない。** 出力するのは作業用の GeoJSON であり、
公開スキーマへの整形と公開API への送信は MapPublisher の役割である。

## 実装機能

画面上部のラジオボタンで 5 つのモードを切り替える。

| モード | 主な操作 |
|--------|---------|
| ファイル入出力（既定） | Excel／GeoJSON の読み込み（複数ファイル・種別選択可）、統計情報の表示、統合 GeoJSON の出力 |
| ルートの位置編集 | ルートの絞り込み・選択、中間点の追加・移動・削除（順序は最近傍法で自動最適化）、ルートのクリア |
| スポットの位置編集 | スポットの追加・移動・削除、名称・区分の編集、重複スポットの抽出（同名かつ 30m 以内） |
| エリアの位置編集 | エリア（多角形）の追加・移動・削除、頂点の追加・移動・削除、名称編集、面積表示 |
| 通行禁止・通行困難地点の登録 | 専用ファイルの入出力、地点の追加・移動・削除、区分・登録理由・備考・解除予定の編集、標高の自動付与 |

読み込み時には次の処理を自動で行う。

- 同一 ID の重複を除外する（`ポイントGPS` と `point` が同じ ID なら `ポイントGPS` を優先）
- `route_{X}_to_{Y}` 形式のルート線を、編集用に中間点（`route_waypoint`）へ展開する（出力時に LineString へ戻す）

## 位置づけ

| 項目 | 内容 |
|------|------|
| 利用者 | 運用担当者専用 |
| 対応端末 | PC専用 |
| 推奨ブラウザ | Chrome / Edge（File System Access API で保存先を選べる。非対応ブラウザではダウンロード保存） |
| 言語 | 日本語のみ |
| オフライン・PWA | 非対応（地理院タイル・標高API の利用にインターネット接続が必要） |
| リポジトリ | `sato4app/MapEditor` |

## 役割分担

| リポジトリ | 役割 |
|---|---|
| GeoReferencer | ハイキングマップ画像をジオリファレンスし、地域別の GeoJSON を出力する |
| **MapEditor** | 地点・ルート・スポット・エリアの編集、通行止め地点の登録。**作業用** GeoJSON を出力する |
| MapPublisher | 作業用ファイルを公開スキーマへ整形し、公開API へ送信する |
| minoh-hiking | 公開API の実装・配信元、および利用者向け表示アプリ |

マーカーの色・形状（`ポイントGPS`・`spot`・`closure`）は minoh-hiking の表示に合わせている。

## 入出力ファイル

| 種類 | 入力 | 出力ファイル名 |
|------|------|---------------|
| GPS ポイント | Excel(.xlsx)。必須列: ポイントID・名称・緯度・経度、任意列: 標高・備考（最大 1000 行） | ― |
| 統合 GeoJSON | `.geojson`（複数同時選択可） | `MapGPS-{YYYYMMDD}_P{ポイント数}_R{ルート数}_S{スポット数}.geojson` |
| 通行止め・通行困難地点 | `.geojson` / `.json`（複数同時選択可） | `Closure-{YYYYMMDD}_C{通行止め件数}_D{通行困難件数}.geojson` |

フォーマットの詳細は [docs/dataspec-geojson-202608.md](docs/dataspec-geojson-202608.md) を参照。

## 開発・動作確認

ES6 モジュール構成のため、ローカルで動かすときは CORS 制限を回避するローカルサーバーが必要。

```bash
python -m http.server 8000
# または
npx serve .
# ブラウザで http://localhost:8000 を開く
```

ビルドプロセスは無い。外部ライブラリは CDN から読み込む。

- Leaflet 1.9.4（地図表示）
- SheetJS (xlsx) 0.18.5（Excel 読み込み）

外部サービスとして、国土地理院の地理院タイル（標準地図）と標高API（通行止め・通行困難地点の標高取得）を使う。
地図の初期表示は箕面大滝（緯度 34.853667, 経度 135.472041）、ズーム 15。

## 制約事項

- ファイル読み込みは累積式で、リセット機能は無い。データをクリアするにはブラウザを再読み込みする
- 通行止め・通行困難地点の区分・登録理由は未選択にできない（新規登録時の既定は「通行止め」「工事」）
- 通行止め・通行困難地点ファイルの公開バージョン（トップレベル `version`）を編集する UI は無い。読み込んだ値を引き継いで出力する
