# MapEditor 利用者の手引

## 1. はじめに

**MapEditor** は、複数の GeoJSON ファイルや Excel(.xlsx) 形式の GPS ポイントデータを地理院地図の上に重ね合わせ、ポイント・ルート・スポット・エリアを編集して、GeoJSON ファイルに出力するためのツールです。あわせて、登山道の**通行止め・通行困難地点**を登録し、専用のファイルとして保存できます。

このマニュアルでは、ツールの起動方法から各編集機能の使い方までを順を追って説明します。

### 1.1 できること

- 複数の地域別 GeoJSON ファイルを 1 ファイルへ統合する
- Excel から GPS ポイントを取り込んで地図上に表示する
- ルートの中間点を地図上で追加・移動・削除して経路を整える
- スポット（見晴台、休憩所など）を地図上で追加・移動・削除する
- 同名で近接した重複スポットをまとめて削除する
- エリア（駐車場・休憩エリアなど多角形）を地図上で描いて編集する
- 通行止め・通行困難な地点を登録し、専用ファイルとして保存する

> 通行止め・通行困難地点は、他のデータ（ポイント・ルート・スポット・エリア）とは**別のファイル**として読み書きします。統合 GeoJSON ファイルには含まれません。

### 1.2 動作環境

- **推奨ブラウザ**: Google Chrome / Microsoft Edge（保存ダイアログを使うため）
- **対応形式**: ポイント GPS は `.xlsx`、地物データは `.geojson`
- **インターネット接続**: 地図の表示に必要です。通行止め・通行困難地点の標高を自動取得する際にも使用します

## 2. 起動方法

### 2.1 起動直後の画面

起動すると、画面いっぱいに**国土地理院地図**が表示され、画面の右上に**操作パネル**が常に表示されます。地図の初期表示は**箕面大滝**（緯度 34.853667, 経度 135.472041）の周辺です。

地図の操作:

| 操作 | 結果 |
|------|------|
| マウスドラッグ | 地図を移動 |
| マウスホイール | ズームイン／アウト |
| 左上または右下の `＋` `－` | ズームイン／アウト |
| 右下のスケール表示 | 現在のズームでの距離目安（メートル） |

---

## 3. 画面の見方

### 3.1 操作パネルの構成

操作パネルの一番上に、5 つのモードを切り替えるラジオボタンがあります。

| モード | 用途 |
|-------|------|
| **ファイル入出力**（既定） | Excel・GeoJSON の読み込み、GeoJSON の出力 |
| **ルートの位置編集** | 既存ルートの中間点を編集 |
| **スポットの位置編集** | スポットの追加・移動・削除、重複の除去 |
| **エリアの位置編集** | エリアの追加・頂点編集・移動・削除 |
| **通行禁止・通行困難地点の登録** | 通行止め・通行困難地点の登録、専用ファイルの読み込み・出力 |

選んだモードに応じて、操作パネルの下半分の表示が切り替わります。

### 3.2 地図上のマーカーの見方

| 表示 | 種別 |
|------|------|
| 緑色の円（半径 6px） | ポイントGPS（Excel 由来） |
| 赤色の円（半径 6px） | ポイント（外部ツール由来） |
| 橙色の小さな菱形 | ルートの中間点 |
| 青色の小さな正方形 | スポット |
| シアン色のポリゴン | エリア |
| 橙色の細いライン | ルート（背景表示） |
| 赤色の ✖ 印 | 通行止めの地点 |
| 橙色の三角形 | 通行困難の地点 |

### 3.3 メッセージ表示

操作の結果は画面中央に小さなトースト（吹き出し）で表示されます。

| 色 | 意味 | 表示時間 |
|----|------|---------|
| 水色 | 成功 | 約 3 秒 |
| 黄色 | 警告 | 約 4.5 秒 |
| 赤色 | エラー | 約 6 秒 |

## 4. ファイル入出力モード

起動直後はこのモードです。データの読み込みと、編集結果のファイル出力を行います。

### 4.1 件数表示の見方

「読み込んだ情報の件数」枠に、現在の保持データ件数が表示されます。

| 項目 | 内容 |
|------|------|
| ファイル | 累積で読み込んだファイル数（Excel・GeoJSON・登録地点ファイルの合計） |
| ポイントGPS | Excel 由来の GPS ポイント数 |
| ポイント | 外部ツール由来の画像変換ポイント数 |
| ルート | ルート（経路）の本数 |
| スポット | スポットの個数 |
| エリア | エリアの件数 |

> ヒント: ファイルを読み込むたびに件数が加算されます。クリアしたい場合はブラウザを再読み込み（F5）してください。
> 通行止め・通行困難地点の件数はここには表示されません。「通行禁止・通行困難地点の登録」モードのパネルで確認してください。

### 4.2 GPS ポイントを Excel から読み込む

1. 「**ポイントGPS(Excel)の読み込み**」ボタンをクリック
2. ファイル選択ダイアログで `.xlsx` ファイルを選択
3. 読み込みが成功すると件数が更新され、地図上に緑色の点が表示される

#### Excel ファイルのフォーマット

1 行目をヘッダーとし、以下の列を含めてください。

| 列 | 必須 | 内容 |
|---|------|------|
| ポイントID | ◯ | 一意の識別子（例: `A-01`） |
| 名称 | ◯ | ポイント名（例: `登山口`） |
| 緯度 | ◯ | 10 進数（例: `34.853667`） |
| 経度 | ◯ | 10 進数（例: `135.472041`） |
| 標高 | | メートル単位 |
| 備考 | | 自由記述 |

#### 注意点

- 1 ファイルあたり最大 **1000 行**（ヘッダー含む）まで読み込みます
- 緯度 −90〜90、経度 −180〜180 の範囲外の行は**自動的にスキップ**されます
- 同じ「ポイントID」が既にある場合、Excel の内容で**上書き**されます。地図上のマーカーも置き換わります
- 上書き件数と新規追加件数はメッセージで通知されます

### 4.3 GeoJSON ファイルを読み込む

1. 「**ファイル(GeoJSON)の読み込み**」ボタンをクリック
2. ファイル選択ダイアログで `.geojson` ファイルを選択（**複数同時選択可**）
3. 読み込み種別選択モーダルが表示される

#### 読み込み種別選択モーダル

選択した全ファイルを集計し、種別ごとの合計件数を表示します。

| チェック項目 | 動作 |
|-------------|------|
| ポイント | チェック時に取り込み（既定では 1 件以上ある種別のみオン） |
| ルート | 同上 |
| スポット | 同上 |
| エリア | 同上 |

「**読み込む**」をクリックすると、チェックされた種別のみが取り込まれます。「**キャンセル**」で中止できます。

> 通行止め・通行困難地点は、この読み込みでは**取り込まれません**（ファイル内に含まれていても無視されます）。これらを読み込むときは「通行禁止・通行困難地点の登録」モードの「ファイル読み込み」を使ってください。

#### 重複ポイントの自動除外

既に読み込み済みのポイント（`type: "point"` または `type: "ポイントGPS"`）と同じ ID のものは**自動的にスキップ**されます。スキップ件数はメッセージで通知されます。

#### ルートの自動展開

`route_{開始ID}_to_{終了ID}` の形式の ID を持つルートは、自動的に編集可能な形（中間点群）に展開され、「ルートの位置編集」モードで操作できるようになります。

### 4.4 GeoJSON ファイルを出力する

1. 「**ファイル(GeoJSON)への出力**」ボタンをクリック
2. （対応ブラウザの場合）ファイル保存ダイアログで保存場所を選択
3. （非対応ブラウザの場合）自動的に既定のダウンロードフォルダへ保存

#### 出力ファイル名

```
MapGPS-{年月日}_P{ポイント数}_R{ルート数}_S{スポット数}.geojson
```

例: `MapGPS-20260817_P15_R5_S8.geojson`

#### 出力内容

- ポイント、ポイントGPS、スポット、エリアはそのまま出力
- ルートは中間点を順番につないだ LineString として再生成され、開始・終了点の現在の座標も `startPointGPS` / `endPointGPS` として書き出されます

> 通行止め・通行困難地点は、この GeoJSON 出力には**含まれません**。「通行禁止・通行困難地点の登録」モードの「ファイル出力」で別ファイルとして保存してください。

データフォーマットの詳細は [GeoJSON データ仕様書](dataspec-geojson-202608.md) を参照してください。

## 5. ルートの位置編集モード

既存のルートを選択し、中間点（waypoint）を編集します。

### 5.1 編集するルートを選ぶ

1. モードを「**ルートの位置編集**」に切り替え
2. ルート詳細情報パネルで、ドロップダウンを使ってルートを絞り込む

| ドロップダウン | 役割 |
|--------------|------|
| 絞り込み（先頭文字） | 開始または終了ポイント ID の**先頭 1 文字**で絞る |
| 絞り込み（終点ポイント） | 完全一致のポイント ID で絞る |
| ルート（フル幅） | 「`{開始ID} ～ {終了ID} ({中間点数})`」形式から選ぶ |
| ↻（リセット） | 全ドロップダウンと選択をリセット |

ルートを選択すると、地図上で次のように表示が変わります。

- **開始・終了ポイント**: 緑なら明るい緑、赤ならピンク、青なら水色に強調
- **中間点**: 橙菱形 → 赤菱形（少し大きく表示）
- **ルート線**: 既存の橙線の上に、赤い線が重ねて描画

### 5.2 中間点を追加・移動する

1. 編集したいルートを選択した状態で、「**追加・移動**」ボタンをクリック
2. ボタンが青く反転し、地図のカーソルが十字に変化
3. 以下の操作で編集

| 操作 | 結果 |
|------|------|
| 地図上の任意の位置をクリック | クリック位置に新しい中間点を追加 |
| 既存の中間点をマウスで掴んでドラッグ | 中間点を移動（ルート線がリアルタイムで追従） |

4. 編集が終わったら「**追加・移動**」ボタンを再クリックして解除

> 中間点は追加・移動の都度、開始ポイントから順に**最も近い順**に並べ直されます（自動最適化）。

### 5.3 中間点を削除する

1. 編集したいルートを選択した状態で、「**削除**」ボタンをクリック
2. ボタンが青く反転し、中間点のカーソルがポインタに変化
3. 削除したい中間点をクリック → 即削除
4. 編集が終わったら「**削除**」ボタンを再クリックして解除

### 5.4 ルート全体を削除する

1. 削除したいルートを選択
2. 「**クリア**」ボタンをクリック
3. 確認ダイアログ「ルート `{開始ID} ～ {終了ID}` を削除しますか？」で「**OK**」を選択

ルートの中間点・線・選択肢がすべて削除されます。開始・終了ポイントは残りますが、ルートとしての関係付けは消えます。再度作成することはできません（このアプリ単体ではルートの新規作成機能はありません）。

> 注意: 「クリア」は**取り消せません**。本当に削除してよいか確認してから OK を押してください。

## 6. スポットの位置編集モード

地図上のスポット（見晴台、休憩所、トイレなど）の編集を行います。

### 6.1 スポットを選ぶ

モードを「**スポットの位置編集**」に切り替えると、スポット詳細情報パネルが表示されます。

| 表示 | 内容 |
|------|------|
| スポット数 | 全スポット数 |
| スポット（ドロップダウン） | スポット一覧 |
| 選択スポット | 選んだスポットの名称（編集可） |
| スポット区分 | 区分（旧跡／神社・仏閣／石碑・記念碑／展望台／休憩所／トイレ／バス停／交差点） |

選び方は 2 通りあります。

- **ドロップダウンから選ぶ**
- **地図上のスポット（青い四角）をクリックする**

選択中のスポットはアクア色（明るい水色）に変わります。

### 6.2 スポット名を変更する

1. スポットを選択
2. 「選択スポット」のテキストボックスをクリックして名称を編集
3. テキストボックスからフォーカスを外す（Tab キーを押すか他の場所をクリック）→ 自動保存

### 6.3 スポット区分を設定する

1. スポットを選択
2. 「スポット区分」ドロップダウンから区分を選ぶ → 即保存

### 6.4 スポットを追加する／移動する

1. 「**追加・移動**」ボタンをクリック（カーソルが十字になる）
2. 以下の操作で編集

| 操作 | 結果 |
|------|------|
| 地図上の任意の位置をクリック | 新規スポットを追加（名称は `仮1`、`仮2`... と自動付与） |
| 地図上のスポットをドラッグ | スポットを移動（どのスポットでも、あらかじめ選ばずに直接掴んで動かせます） |

3. 編集が終わったら「**追加・移動**」ボタンを再クリックして解除

> 新規追加したスポットは自動的に選択状態になります。続けて名称を変更したり、区分を設定してください。

### 6.5 スポットを削除する

1. 削除したいスポットを選択
2. 「**削除**」ボタンをクリック
3. 確認ダイアログ「スポット「`{name}`」を削除しますか？」で「**OK**」を選択

### 6.6 重複スポットをまとめて整理する

「**重複スポット抽出**」機能を使うと、地図上の指定範囲内で**同じ名前**かつ**30 メートル以内**にあるスポットをまとめて見つけて、不要なものを削除できます。

1. 「**重複スポット抽出**」ボタンをクリック（地図のドラッグ操作が一時的に無効化される）
2. 重複を調べたい範囲をマウスで**ドラッグして長方形で囲む**
3. 範囲内の重複スポットがアクア色に変色する（重複件数がメッセージで通知される）
4. 不要なスポット（アクア色のもの）をクリック → 即削除
5. 削除のたびに自動で再判定が行われ、残った重複件数が表示される
6. 終了するときは「**重複スポット抽出**」ボタンを再クリック

> アクア色になっているスポットは「同じ名前で 30m 以内に別のスポットがある」ことを意味します。残したい方は触らず、削除したい方だけクリックしてください。

## 7. エリアの位置編集モード

地図上のエリア（駐車場、休憩エリアなど多角形の領域）の編集を行います。

### 7.1 エリアを選ぶ

モードを「**エリアの位置編集**」に切り替えると、エリア編集パネルが表示されます。

| 表示 | 内容 |
|------|------|
| 件数 | 全エリア数 |
| 選択（ドロップダウン） | エリア一覧 |
| 名称 | 選択中エリアの名称（編集可） |
| 頂点 | 選択中エリアの頂点数（読み取り専用） |
| 面積 | 選択中エリアの推定面積（㎡、読み取り専用） |

選び方:

- **ドロップダウンから選ぶ**
- **地図上のエリア（シアン色のポリゴン）をクリックする**

選択中のエリアは境界線が太くなり、各頂点に黄色い丸が表示されます。

### 7.2 エリア名を変更する

1. エリアを選択
2. 「名称」のテキストボックスを編集
3. フォーカスを外す → 自動保存（地図上の中央ラベルも更新）

### 7.3 頂点を編集する

エリアを選択すれば、ボタンを押さなくても頂点編集ができます。

| 操作 | 結果 |
|------|------|
| 黄色い頂点をドラッグ | 頂点位置を移動（ポリゴン形状・面積もリアルタイム更新） |
| 黄色い頂点を**右クリック** | 頂点を削除（最低 3 頂点は残る） |
| 境界線（ポリゴンの辺）の上をクリック | クリック位置の最近傍に新しい頂点を挿入 |

> 境界線への挿入は、辺から**約 10 ピクセル以内**をクリックしたときだけ反応します。

### 7.4 新しいエリアを追加する

1. 「**エリア追加**」ボタンをクリック（カーソルが十字に変化）
2. 地図上をクリックして頂点を順番に追加（赤色の暫定ラインが表示される）
3. **始点付近をクリック**（始点から画面上 20 ピクセル以内）するとエリアが確定
4. 確定後は自動的に新規エリアが選択され、編集できる状態になる
5. やめたい場合は「**エリア追加**」ボタンを再クリック

新規エリアの名称は `エリア1`、`エリア2`... と自動付与されます。後から名称を編集してください。

> エリアは**3 点以上**の頂点が必要です。2 点以下で確定しようとすると警告が表示されます。

### 7.5 エリア全体を移動する

1. 移動したいエリアを選択
2. 「**エリア移動**」ボタンをクリック
3. エリアの中央にマゼンタ色の丸が表示される
4. その丸をドラッグするとエリア全体が平行移動する（形状や面積は変わらない）
5. 終了するときは「**エリア移動**」ボタンを再クリック

### 7.6 エリアを削除する

1. 削除したいエリアを選択
2. 「**エリア削除**」ボタンをクリック
3. 確認ダイアログ「エリア「`{name}`」を削除しますか？」で「**OK**」を選択

## 8. 通行禁止・通行困難地点の登録モード

登山道の通行止め箇所や通行が難しい箇所を地点として登録し、専用のファイルに保存します。

> このモードで扱うデータは、**他のデータとは別のファイル**です。ポイント・ルート・スポット・エリアの GeoJSON（`MapGPS-…`）には含まれません。

### 8.1 パネルの見方

モードを「**通行禁止・通行困難地点の登録**」に切り替えると、「登録地点」パネルが表示されます。

| 表示・入力 | 内容 |
|-----------|------|
| ファイル読み込み／ファイル出力 | 登録地点の専用ファイルを読み書き |
| 登録地点数 | 登録済みの地点数。右側に「通行止め ◯ / 通行困難 ◯」の内訳を表示 |
| 登録地点（ドロップダウン） | 登録済み地点の一覧 |
| 選択地点 | 選んだ地点の名称（編集可） |
| 備考 | 選んだ地点の補足説明（編集可） |
| 区分 | 通行止め／通行困難（どちらかが必ず選択されます） |
| 登録理由 | 工事／倒木／落石／その他（いずれかが必ず選択されます） |
| 追加・移動／削除 | 地点の追加・移動、削除 |

### 8.2 地点を登録する

1. 「**追加・移動**」ボタンをクリック（ボタンが青く反転し、カーソルが十字になる）
2. 地図上の通行止め箇所をクリック → その位置に地点が追加される
3. 追加した地点は自動的に選択状態になるので、続けて内容を設定する
   - 「選択地点」に名称を入力（初期値は `地点1`、`地点2`...）
   - 「区分」で**通行止め**または**通行困難**を選ぶ（初期値は**通行止め**）
   - 「登録理由」で工事／倒木／落石を選ぶ（初期値は**工事**。当てはまるものがなければ「その他」）
   - 必要に応じて「備考」に補足を書く

> 区分と登録理由は、どちらも**未選択にはできません**。初期値のままでよければそのまま次の地点を追加できます。
4. 続けて別の地点を追加できます
5. 終わったら「**追加・移動**」ボタンを再クリックして解除

> 地点を追加すると、その場所の**標高**が国土地理院のデータから自動取得され、「標高を取得しました（◯m）」と表示されます。取得できない場合も地点の登録自体は成功します。

### 8.3 地点を選ぶ・内容を修正する

選び方は 2 通りあります。

- **「登録地点」ドロップダウンから選ぶ**
- **地図上の地点（✖印・三角形・`?`）をクリックする**

選択中の地点はアクア色（明るい水色）に変わります。

| 修正する項目 | 保存されるタイミング |
|-------------|-------------------|
| 選択地点（名称）、備考 | テキストボックスからフォーカスを外したとき |
| 区分、登録理由 | ラジオボタンを選んだ瞬間 |

区分を変えると、地図上のマークも切り替わります（通行止め＝赤い ✖ 印、通行困難＝橙の三角形）。

> 内容を変更するたびに、その地点の「更新日」が当日の日付で記録されます。更新日は地図上の地点をクリックしたときのポップアップで確認できます。

### 8.4 地点を移動する

1. 「**追加・移動**」ボタンをクリック
2. 地図上の地点を直接ドラッグして移動（どの地点でも、あらかじめ選ばずに動かせます）
3. 終わったら「**追加・移動**」ボタンを再クリックして解除

移動すると、その位置の標高が再取得されます。

> 注意: 「追加・移動」モード中は、**地図をクリックすると新しい地点が追加**されます。移動だけを行いたい場合は、地点そのものを掴んでドラッグしてください。

### 8.5 地点を削除する

1. 削除したい地点を選択
2. 「**削除**」ボタンをクリック
3. 確認ダイアログ「地点「`{名称}`」を削除しますか？」で「**OK**」を選択

### 8.6 ファイルを読み込む

前回出力したファイルを読み込んで、続きから編集できます。

1. 「**ファイル読み込み**」ボタンをクリック
2. `.geojson` / `.json` ファイルを選択（**複数同時選択可**）
3. 読み込んだ件数がメッセージで表示される

読み込み時には次の処理が自動的に行われます。

- 既に登録済みの地点と**同じ ID の地点はスキップ**されます（スキップ件数を通知）
- ID が無い地点には `C-01`、`C-02`... の形式で ID を自動付与します
- 区分が無い、または正しくない値（`unknown` など）の地点は「**通行止め**」として取り込みます（必要に応じて読み込み後に修正してください）

> 統合 GeoJSON（`MapGPS-…`）を誤って選んでも、ポイント・ルート・スポット・エリアは取り込まれません。「通行止め・通行困難地点のデータが見つかりませんでした」と表示されます。

### 8.7 ファイルを出力する

1. 「**ファイル出力**」ボタンをクリック
2. （対応ブラウザの場合）保存ダイアログで保存場所を選択

#### 出力ファイル名

```
Closure-{年月日}_C{通行止めの件数}_D{通行困難の件数}.geojson
```

例: `Closure-20260817_C3_D2.geojson`（通行止め 3 件・通行困難 2 件）

データフォーマットの詳細は [GeoJSON データ仕様書](dataspec-geojson-202608.md) を参照してください。

## 9. 典型的な作業の流れ

### 9.1 複数の地域別 GeoJSON を 1 ファイルに統合する

1. **ファイル入出力**モードで「ファイル(GeoJSON)の読み込み」をクリック
2. 統合したい複数の `.geojson` を選択
3. 読み込み種別選択モーダルで取り込む種別を選ぶ
4. 必要に応じて Excel から GPS ポイントを追加読み込み
5. 必要に応じて他のモードで内容を確認・微修正
6. 「ファイル(GeoJSON)への出力」で統合ファイルを保存

### 9.2 ルートの中間点を整える

1. **ファイル入出力**モードでルートを含む GeoJSON を読み込む
2. **ルートの位置編集**モードに切り替え
3. ドロップダウンで対象ルートを選択
4. 「追加・移動」で中間点をクリック追加・ドラッグ移動
5. 「削除」で不要な中間点を削除
6. **ファイル入出力**モードに戻り、出力

### 9.3 重複スポットを掃除する

1. **ファイル入出力**モードでスポットを含む GeoJSON を読み込む
2. **スポットの位置編集**モードに切り替え
3. 「重複スポット抽出」をクリック
4. 重複が多そうなエリアをドラッグで囲む
5. アクア色になった残したくないスポットをクリックして削除
6. 終了して「ファイル(GeoJSON)への出力」

### 9.4 エリアを新規作成する

1. **エリアの位置編集**モードに切り替え
2. 「エリア追加」をクリック
3. 地図上で頂点を順番にクリック → 始点付近を最後にクリックして確定
4. 「名称」を意味のある名前に変更
5. 必要なら頂点をドラッグ／右クリックで微調整
6. **ファイル入出力**モードに戻り、出力

### 9.5 通行止め情報を更新する

1. **ファイル入出力**モードで、地形の目印になる GeoJSON（ルート・スポット等）を読み込む
2. **通行禁止・通行困難地点の登録**モードに切り替え
3. 前回の `Closure-….geojson` があれば「ファイル読み込み」で取り込む
4. 「追加・移動」で新しい通行止め箇所を追加し、区分・登録理由・備考を設定
5. 復旧した箇所は選択して「削除」
6. 「ファイル出力」で保存

## 10. 困ったときは

### 10.1 操作モードを変えたら表示が変わってしまった

各モードの編集状態（追加・移動モードや削除モードなど）は、**他のモードに切り替えた時点で自動解除**されます。続きの編集を行うには、もう一度モードを選び直してから編集ボタンを押してください。

### 10.2 ボタンを押しても何も起こらない

一部の操作は、**対象を先に選択**しないと実行できません。

| 操作 | 事前に必要な選択 |
|------|----------------|
| ルートの追加・移動／削除／クリア | ルート選択 |
| スポットの削除 | スポット選択 |
| エリアの移動／削除 | エリア選択 |
| 登録地点の削除 | 登録地点の選択 |

なお、スポットや登録地点の「追加・移動」では、モードに入っている間はどの地点でも直接ドラッグして移動できます（あらかじめ選択する必要はありません）。

警告メッセージが表示された場合は、メッセージの内容（「ルートを選択してください」など）に従ってください。

### 10.3 ファイルを読み込んでも地図に何も表示されない

- 読み込み種別選択モーダルですべてオフにしていませんか？
- 緯度経度が範囲外（緯度は ±90、経度は ±180）になっていませんか？
- データの座標が日本国内であれば、画面の左上にある「ホーム」位置（箕面大滝）から大きく外れている可能性があります。マウスホイールで地図を縮小して全体を確認してください
- 同じ ID のポイントが既にある場合、自動でスキップされています（スキップ件数のメッセージで確認）
- 通行止め・通行困難地点は「ファイル(GeoJSON)の読み込み」では取り込まれません。「通行禁止・通行困難地点の登録」モードの「ファイル読み込み」を使ってください

### 10.4 上書きされたくないのに Excel で上書きされてしまった

Excel の同 ID は**強制的に上書き**されます。ID を変更してから読み込むか、ブラウザを再読み込みしてやり直してください。

### 10.5 「標高の取得に失敗しました」と表示される

通行止め・通行困難地点の標高は、国土地理院のインターネット上のデータから取得しています。次の場合は取得できません。

- インターネットに接続していない
- 海上など、標高データが存在しない場所を指定した
- 一時的に国土地理院のサービスへ接続できない

標高が取得できなくても、地点の登録・保存はそのまま行えます（標高だけがファイルに含まれません）。位置を少し動かして再取得を試すこともできます。

### 10.6 削除した内容を元に戻したい

このアプリには**取り消し（Undo）機能はありません**。「クリア」「削除」操作は確認ダイアログで内容をよく確認してから OK を押してください。

万一誤って削除した場合、出力前であればブラウザを再読み込みして元のファイルから読み直してください（編集中の内容はすべて失われます）。

### 10.7 保存先のダイアログが出ない

File System Access API に対応していないブラウザ（古い Firefox など）では、ダイアログは表示されず、自動的に**既定のダウンロードフォルダ**へ保存されます。Chrome / Edge をご利用ください。
